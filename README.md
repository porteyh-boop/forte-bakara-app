# פורטה בקרה (FORTE)

מערכת דיגיטלית לבקרת שירות מעליות — גרסת דמו.

**יהודה פורטה · שמאות וליווי מקצועי למעליות**

## תיאור

פורטה בקרה מאפשרת לוועדי בתים וחברות ניהול לעקוב אחר מצב המעליות, לדווח תקלות, לצפות בהיסטוריה ולקבל תמונת מצב תפעולית — הכל ממכשיר נייד.

גרסת הדמו הנוכחית פועלת עם **נתוני דמה בלבד** (בניין לדוגמה, 3 מעליות, 10 תקלות). אין חיבור למסד נתונים או ל-API חיצוני.

### דפים זמינים (תצוגת לקוח)

| נתיב | תיאור |
|------|--------|
| `/` | דף בית — סטטיסטיקות, תקלות פתוחות, גרפים |
| `/report` | דיווח תקלה חדשה |
| `/history` | היסטוריית תקלות |
| `/building` | פרטי בניין ומעליות |

### דפים פנימיים (מומחה בלבד)

| נתיב | תיאור |
|------|--------|
| `/expert` | מסך ניתוח מקצועי |
| `/expert/print` | דוח להדפסה / שמירה כ-PDF |

> בפריסת הדמו הציבורית דפי המומחה **חסומים** ומסך המומחה **לא מוצג** בתפריט.

## דרישות

- Node.js 20+
- npm 10+

## התקנה והרצה

```bash
npm install
```

### פיתוח מקומי

```bash
npm run dev
```

פתחו [http://localhost:3000](http://localhost:3000)

### בנייה לפרודקשן

```bash
npm run build
```

### הרצת פרודקשן מקומית

```bash
npm start
```

### בדיקות איכות

```bash
npm run qa
```

## מבנה הפרויקט

```
app/           — דפי Next.js (App Router)
components/    — רכיבי UI
lib/           — נתוני דמו, אנליטיקה, מיתוג, תצורה
scripts/       — בדיקות QA
middleware.ts  — חסימת /expert ללקוח
```
